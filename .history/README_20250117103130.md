Code Quiz Game

This is a CLI-based Code Quiz Game that challenges the user with multiple-choice questions on topics like React.js, Node.js, CSS, React Native, MongoDB, and UX/UI Design. The game is timed, with 30 seconds allowed per question.

How to Run the Game

Prerequisites:

Ensure you have Node.js installed on your computer.

A terminal or command line interface is required to run the game.

Download or Clone the Repository:

git clone sbu
cd <repository_folder>

Run the Game:
Execute the following command in the terminal:

node codegame.js

Play:

Enter your name when prompted.

Answer the multiple-choice questions by typing the number corresponding to your answer.

Each question has a 30-second time limit. Make sure to answer quickly!

Game Rules

A question will be displayed along with its topic and four options.

Players need to choose the correct answer by entering a number (1-4).

Each correct answer earns 1 point.

Time runs out? You'll miss the chance to answer the question.

Features

Topics: Covers popular topics like React.js, Node.js, CSS, MongoDB, etc.

Timed Questions: Adds excitement with a 30-second countdown for each question.

Interactive Input: Real-time input and feedback for correct and incorrect answers.
